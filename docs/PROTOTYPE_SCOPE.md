# Prototype Scope

## Goal

Prove one thing first:

> Typing + combat + upgrades is genuinely fun.

Target prototype run: **10 minutes**.

## Included

- 1 arena
- 1 stationary player
- 3 weapons
- 3 effects
- 2 elemental reactions
- 10-15 upgrades
- 3 priority enemy types
- 1 elite
- 1 boss
- Standard Words mode
- Narrative mode
- Basic XP and level-up loop
- Clear hit, kill, typing, and combo feedback

## Not Included Yet

- Permanent progression
- Full Story Mode
- Endless Mode
- Large skill tree
- Multiple maps
- Multiple characters
- Steam integration
- Final art
- Final audio
- Leaderboards

## First Vertical Slice

The very first playable build is intentionally smaller than the prototype:

1. Display a short moving word queue.
2. Correct keystrokes fire at enemies.
3. Word completion produces a stronger combat effect.
4. Enemies approach the player.
5. Enemies can be killed.
6. Kills grant XP.
7. Missed inputs reset the typing streak.
8. All simulation is centralized rather than one heavy scene node per enemy.

No upgrade selection is required for this first slice.
